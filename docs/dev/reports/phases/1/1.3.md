Added a browser regression that failed on `defaultPrevented=false`, then separated admissible arrow default handling from one-shot command translation. Disabling Playwright focus emulation and a lifecycle freeze/restore probe did not change them. This verifies handler behavior, not native desktop tab switching; manual testing in a normal desktop browser remains a compatibility evidence limit. No product defect or altered requirement is inferred from headless-shell behavior.
